# Mercadinho da Esquina

Versão web do jogo (1.8.1), para jogar no iPhone pelo Safari e "Adicionar à Tela de Início".

Link: https://danielcamposdasilva-tech.github.io/mercadinho/

Ao publicar versão nova, troque `VERSAO` em `sw.js`.

Página de download (Android + iPhone) para divulgar: https://danielcamposdasilva-tech.github.io/mercadinho/baixar/
O APK atual fica em `baixar/mercadinho-da-esquina-1.8.1.apk` (os da 1.2 a 1.8 continuam lá para links antigos). Ao lançar versão nova: troque o arquivo e o texto da versão em `baixar/index.html`, atualize `versao.json` (avisa quem tem o APK instalado) e a VERSAO em `sw.js`.
